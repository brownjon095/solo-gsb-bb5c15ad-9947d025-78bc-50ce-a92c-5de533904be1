单次重组 · 输入

负载从偏移 0 到该长度，区间左闭右开。
起始偏移 优先级 十六进制内容（允许空格 / 冒号分隔）
「重组」按录入顺序先到先得（同级异值即冲突）；「优先级恢复」逐字节只采用覆盖该位置的 最高优先级片的裁决：同级异值仍标冲突，同级同值取最早录入片，更低优先级片的异值被忽略。 优先级为整数（默认 0，负数亦可），越大越优先。
